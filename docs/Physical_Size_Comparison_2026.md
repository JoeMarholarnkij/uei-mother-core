## 2. จุดเด่นด้าน "ความหนาแน่นพลังงาน" (Power Density)

### 2.1 ทำไม sCO2 ถึงเล็กกว่า 10-20 เท่า?
1. **Supercritical Fluid Property:** ในสภาวะเหนือวิกฤต CO2 จะมีความหนาแน่นสูงมาก ทำให้กังหันขนาดเส้นผ่านศูนย์กลางเพียง **15-20 เซนติเมตร** สามารถรับพลังงานความร้อนมหาศาลได้เท่ากับกังหันไอน้ำขนาดเมตรกว่าๆ
2. **Extreme RPM:** ใบพัด Bionic ของเราหมุนที่ความเร็ว **45,000 - 120,000 รอบต่อนาที** ทำให้มอเตอร์ปั่นไฟ (Generator) มีขนาดจิ๋วแต่จ่ายไฟแรง (High Frequency Permanent Magnet Generator)
3. **Modular Design:** ระบบเป็นแบบ Closed-loop ไม่ต้องมีหอหล่อเย็น (Cooling Tower) ขนาดใหญ่เหมือนโรงไฟฟ้าทั่วไป

## 3. การประยุกต์ใช้งานเชิงพื้นที่ (Deployment Scenarios)
- **Urban Integration:** สามารถติดตั้งในห้องเครื่องใต้ดินของคอนโด หรือบนดาดฟ้าได้โดยไม่ต้องเสริมโครงสร้างอาคารหนัก
- **Mobile Power:** ติดตั้งบนรถบรรทุกขนาดเล็กเพื่อเป็นหน่วยปั่นไฟเคลื่อนที่ในเขตภัยพิบัติ
- **Aerospace:** น้ำหนักที่เบาเพียง 180 กก. ทำให้สามารถติดตั้งเป็นแหล่งพลังงานหลักของ **AeroHome V1** ได้จริง
