## 🏛️ The Four Pillars

### 1. The Root (Local Realm)
*   **Purpose:** Deep retrieval and storage of personal knowledge and proprietary data trees.
*   **Assets:** KJV Bible studies, Joe's Brother documents, Nexus POINT scripts, Metro Luxe Ratchada logs.
*   **Tech Stack:** Local Vector Database (ChromaDB, FAISS).
*   **Principle:** Air-Gapped Logic and the Sovereignty Principle for data privacy.

### 2. The Cloud (Cloud Realm)
*   **Purpose:** High-level reasoning, complex processing, and broad knowledge retrieval.
*   **Tech Stack:** Gemini API, Gemini 2.5 Flash, Gemini CLI (Node.js/NPM), Browser-Use (Playwright).
*   **Value:** High-uptime intelligence and live data access.

### 3. The Pulse (Hybrid)
*   **Purpose:** Real-time multimodal voice and vision interaction (Eden Live).
*   **Tech Stack:** Gemini Multimodal Live API, WebSockets, Whisper.cpp, MLX-Whisper, Kokoro-82M, Pipecat, WebRTC.
*   **Logic:** Barge-in logic, 'Thinking Out Loud' experience, and multimodal flow.

### 4. The Flow (River)
*   **Purpose:** Opal-style logic generator for task progression and sprint management.
*   **Tech Stack:** MCP (Model Context Protocol), n8n, React flow UI, Hyper Scrum, Sprint-Voice Reports.
*   **Workflow:** Seed to Harvest execution of Hyper Scrum tasks.
